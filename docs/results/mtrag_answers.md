# Качество ответов: MTRAG, 9 систем

Генератор `gemma-4-26B-A4B-it` и судья `qwen3.8` получают top-5 пассажей системы, до 1500 символов на пассаж. Оценки выставляются по шкале 1–5. На 777 задачах MTRAG с qrels каждая из девяти систем сгенерировала ответ. Валидные оценки по всем трём критериям получены для 6991 из 6993 ответов.
