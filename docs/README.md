# Документация НИР

В [README проекта](../README.md) приведены основные результаты и быстрый запуск BM25.

## Руководства

- [Воспроизведение экспериментов](reproduction.md) описывает настройку, полные прогоны MTRAG и MTRAG-UN, перенос Adaptive-RAG, сравнение роутеров с историей и без неё и пути к результатам.
- [Методика](methodology.md) описывает выборки, стратегии, создание меток Adaptive-RAG, критерии LLM-судьи и статистические тесты.
- [Журнал исследования](journal.md) хранит ход экспериментов, промежуточные результаты и обоснования решений. Записи расположены от новых к старым.

## Результаты на MTRAG

| Отчёт | Содержание |
|---|---|
| [Поиск](results/mtrag_analysis.md) | Анализ по 30 стратегиям на 777 задачах с qrels, разбивка по ходам, доменам и типам вопросов, оценки оракула. |
| [Качество ответов и стоимость](results/mtrag_answers.md) | Девять систем, три критерия судьи, сравнение по correctness и расход LLM-токенов. |
| [Калибровка судьи v2](results/judge_calibration_qwen_v2.md) | Использованная в итоговом сравнении версия. Сопоставление с человеческими оценками на 477 ответах и [оценки по ответам](results/judge_calibration_qwen_v2.jsonl). |

Промежуточные отчёты сохранены для истории эксперимента: [BM25, 3 стратегии](results/mtrag_bm25_analysis.md), [без реранкера, 12 стратегий](results/mtrag_norerank_analysis.md), [с реранкером, 24 стратегии до CHIQ-AD](results/mtrag_rerank_analysis.md) и [калибровка судьи v1](results/judge_calibration_qwen.md) с [оценками по ответам](results/judge_calibration_qwen.jsonl).

## Результаты на MTRAG-UN

[Отчёт MTRAG-UN](results/mtragun.md) содержит сравнение восьми систем, парные тесты, стоимость, результаты Adaptive-RAG, обученного на MTRAG, и контрольное сравнение для RQ2.

Сырые прогоны и CSV-сводки CLI сохраняет локально в `runs/`. В Git сохранены методика и сводные отчёты из `docs/`.
